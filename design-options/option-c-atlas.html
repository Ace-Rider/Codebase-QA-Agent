Answer

后端重包装事件，前端才能更稳定地展示 Agent

如果前端直接消费模型原始流，它就要自己处理内容拼接、工具调用片段合并、最终状态判断，这会让页面逻辑变得很乱。后端先把原始流整理成统一事件，再交给前端，页面就能更清楚地区分“状态”“回答”“步骤”“最终结果”。

  • 后端负责消化复杂性
  • 前端负责组织可视化结构
  • 这样更适合做出稳定的简历项目
